# Didactic guide for this paper

Write this as a learning paper. The target reaction is: "I understand why this
result must be true."

Before introducing a determinant, coordinate change, decomposition,
derivative, eigenproblem, or optimizer, explain the question it answers and
why that tool helps. State what the tool reveals, what it suppresses, and
whether another route reaches the same result.

For central results:

- use more than one viewpoint when each view adds information;
- motivate eigenvectors as invariant directions before solving for them;
- interpret determinants as area or volume scaling and rank loss;
- derive Lagrange multipliers from touching level sets and parallel normals;
- explain KKT as the active-boundary extension;
- whiten weighted resource ellipsoids before introducing generalized
  eigenvalue problems;
- show how new coordinates could have been discovered;
- separate structural conclusions from parameter-dependent ones;
- ask what changes when assumptions are relaxed;
- include a small normalized thought experiment;
- use figures to show transformations, not only final results;
- end important developments with a short algebra--geometry--physics--
  engineering synthesis.
